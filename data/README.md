# BidGuard 数据目录说明

| 目录        | 存放什么                               | 能否修改原文件                 | 是否提交Git    |
| ----------- | -------------------------------------- | ------------------------------ | -------------- |
| raw         | `官方下载的原始PDF、DOCX、XLSX、ZIP` | `否`                         | `否`         |
| interim     | `OCR、文本提取、解压等中间结果`      | `不手工修改，可重新生成`     | `否`         |
| processed   | `结构化条款、表格和Chunk`            | `不手工修改，由程序重新生成` | `否`         |
| annotations | `人工确认的条款和标准答案`           | `可以，但必须记录修改`       | `有条件提交` |
| samples     | `脱敏且允许公开的少量演示数据`       | `可以`                       | `审核后提交` |

## 数据管理规则

1. `raw`中的原始文件下载后不得修改或覆盖，每个文件都要计算SHA-256。
2. 每份数据必须记录来源页面、下载地址、发布机构、发布日期和采集时间。
3. 真实招标文件与合成投标响应必须分开存放，并明确标记真实性。
4. 公开访问不代表允许重新发布；未确认再分发权限的文件不得提交Git。
5. `interim`和`processed`必须能由程序重新生成，不能依赖人工修改结果。
6. 人工标注必须记录对应的原始文件、页码、章节和修改记录。
7. 包含姓名、电话、身份证号、签章等信息的数据，公开前必须检查和脱敏。
8. 下载失败、需要登录或格式损坏的文件也要记录，不能只保留成功数据。
9. 划分训练集和测试集时以采购项目为单位，避免同一项目的数据泄漏到两个集合。


### mainfest.csv 列名称说明

| 列名                       | 含义                     | 数据来源                   |
| -------------------------- | ------------------------ | -------------------------- |
| `record_id`              | 文件唯一编号             | 我们生成；一份附件一个编号 |
| `project_id`             | 采购项目内部编号         | 我们生成；同项目附件共用   |
| `project_code`           | 官方项目编号             | 公告网页或招标文件         |
| `project_name`           | 官方项目名称             | 公告网页                   |
| `domain`                 | 项目所属IT领域           | 根据项目内容人工分类       |
| `artifact_role`          | 文件角色                 | 根据文件类型分类           |
| `authenticity`           | 真实或合成数据           | 根据数据来源判断           |
| `publisher`              | 信息发布平台             | 来源网站                   |
| `procuring_entity`       | 实际采购单位             | 公告中的“采购单位”       |
| `procurement_agency`     | 采购代理机构             | 公告中的“代理机构”       |
| `source_page_url`        | 公告页面地址             | 浏览器地址栏               |
| `download_url`           | 附件直接下载地址         | 右键附件复制链接           |
| `published_date`         | 公告发布日期             | 公告网页                   |
| `collected_at`           | 我们采集数据的时间       | 本机当前时间               |
| `original_filename`      | 官方附件名称             | 公告附件区域               |
| `local_path`             | 下载后的本地相对路径     | 保存文件后填写             |
| `media_type`             | 文件媒体类型             | HTTP响应或文件检测         |
| `byte_size`              | 文件字节数               | 下载后的文件属性           |
| `sha256`                 | 文件内容指纹             | 下载后使用哈希工具计算     |
| `download_status`        | 下载状态                 | 根据实际操作记录           |
| `access_level`           | 获取文件是否需要登录     | 根据访问过程判断           |
| `redistribution_status`  | 能否重新公开发布         | 根据授权和使用规则判断     |
| `contains_personal_data` | 是否包含姓名、电话等信息 | 下载后人工或程序检查       |
| `redaction_status`       | 是否完成脱敏             | 根据数据审核流程填写       |
| `notes`                  | 特殊情况和补充说明       | 采集人员填写               |
